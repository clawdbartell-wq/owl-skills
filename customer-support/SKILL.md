# Customer Support Skill

## Purpose
Provide excellent customer support — fast, empathetic, and effective.

## Response Framework

### 1. Acknowledge
"Thank you for reaching out. I understand [issue]."

### 2. Empathize
"I can see how that would be frustrating."

### 3. Resolve
"Here's what I can do: [solution]"

### 4. Confirm
"Does that resolve your issue?"

### 5. Close
"Is there anything else I can help with?"

## Ticket Triage
- **Critical**: System down, data loss, security breach → Immediate
- **High**: Feature not working, billing issue → <2 hours
- **Medium**: How-to questions, minor bugs → <24 hours
- **Low**: Feature requests, general inquiries → <48 hours

## Response Templates
Keep templates for common issues but always personalize.

## Metrics
- First response time: <1 hour
- Resolution time: <24 hours
- CSAT score: >90%
- Ticket volume: Track trends weekly
